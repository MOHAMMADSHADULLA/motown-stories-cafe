## ✨ Features

- 🎬 **Cinematic Hero** — Full-screen parallax background with smooth entrance animation
- 🍽️ **Interactive Menu** — 5 category tabs: Coffee & Tea · Mocktails · Milkshakes · Food · Desserts
- 🖼️ **Photo Gallery** — 12 authentic café photos with lightbox, keyboard nav & touch swipe
- ⭐ **Verified Reviews** — 3 real Google reviews (no fabricated testimonials)
- 📍 **Visit Us** — Embedded Google Map, click-to-call, WhatsApp enquiry & table reservation
- 📱 **Mobile Sticky Bar** — One-tap access to Menu, WhatsApp, Reserve & Call
- 🔄 **Smooth Scroll** — Locomotive Scroll with scroll-reveal animations
- 🌙 **Dark Automotive Theme** — Charcoal backgrounds, amber accents, vintage feel
- ♿ **Accessible** — ARIA labels, keyboard navigation, focus management, `prefers-reduced-motion`

## 🚀 Getting Started

### Run Locally

**Option 1 — Python (no install needed)**
```bash
cd motown-stories-cafe
python -m http.server 8000
```
Then open → **http://localhost:8000**

**Option 2 — Node.js**
```bash
npx serve .
```

**Option 3 — VS Code**
Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension → right-click `index.html` → **Open with Live Server**

---

## 🌐 Deploy on GitHub Pages

1. Go to **Settings → Pages**
2. Source: **`main`** branch → **`/ (root)`**
3. Click **Save**
4. Live at: `https://mohammadshadulla.github.io/motown-stories-cafe`
